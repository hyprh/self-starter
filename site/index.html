An open-source plugin for Codex

Codex,
unprompted.

Tell Codex what to keep an eye on: a price, your brokerage account, a CI pipeline, a release feed. It writes a small watcher, you approve it, and from then on it checks quietly without spending a token. When something changes, Codex takes the first step and comes back to you.

It acts on its own

The watcher runs in the background without calling a model. It fires once when the condition becomes true, not on every check, and waits for it to clear before it can fire again.

Codex picks the task back up in your thread, or works in a thread of its own while you are away, and tells you what it found.

Proactive, within limits you set

An agent that acts on its own has to earn it. These rules hold for every watcher.

Sandboxed watchers

Watchers run in Deno with network access only to the sites they declare. No files, no programs, no imports from the internet.

Nothing runs without you

You approve the code and its permissions before anything is scheduled. If either changes later, the watcher stops until you approve again.

Data is never instructions

What a watcher sees reaches Codex as quoted data, and a task handling an alert cannot create or change alerts.

Keys stay with you

API keys and your email password live in files only you can read. A key goes only to watchers that cannot reach any other site.

No runaway costs

No model runs while waiting. Codex runs at most 20 times a day by default, one at a time.

Every alert is on record

Ask why something fired, or why it did not: each check, each alert and what Codex did about it is kept, and readable from Codex or the terminal.

Where it finds you

Each watcher reports where you asked it to.

Your threadThe task comes back to the conversation where you asked, as soon as you are there.
Its own threadLong-running watches get a thread named after them that Codex works in while you are away.
DesktopA notification on macOS or Linux that opens the thread.
EmailAny SMTP account, for the things you want to read on your phone.

Install

Two minutes, then ask Codex to watch something.

  • macOS or Linux
  • Node.js 20 or newer
  • The Codex CLI or the Codex app
# get it
git clone https://github.com/hyprh/SelfReflection.git self-starter
cd self-starter
npm install && npm link

# add the plugin to Codex and start the background service
ctrig install
ctrig doctor

# optional: email notifications
ctrig channel email --to you@example.com --host smtp.example.com --user you@example.com
