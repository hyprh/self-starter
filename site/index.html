Install for Codex

macOS or Linux · Node.js 20+ · Codex app or CLI

codex plugin marketplace add hyprh/self-starter
codex plugin add self-starter@self-starter

Restart the Codex app or start a new CLI session. The first start installs the runtime and background service; allow a minute or two.

Install the ZCode source preview

macOS or Linux · Node.js 24.14+ · Configured and authenticated ZCode CLI

git clone https://github.com/hyprh/self-starter.git
cd self-starter
npm ci
npm run build
node dist/src/cli/main.js install --zcode /absolute/path/to/zcode
node dist/src/cli/main.js doctor

Use the actual ZCode CLI path, rather than the desktop app launcher. Keep this checkout available and start a new ZCode session after installation.

ZCode support is on main and is not included in the published v0.0.3 runtime. Source installation guide →

How it works

Code keeps watch. Your agent does the work.

01 / DEFINE

Describe the condition

Your agent writes a small TypeScript probe for a file, command, local service or API, and tries it before activation.

02 / WAIT

Let local code check

A background service runs the probe, with no model calls during scheduled checks. The engine handles deduplication, cooldowns and expiry.

03 / ACT

Get the next step done

When the condition is met, Self-Starter hands your task to the agent or sends a notification. Results can reach you on the desktop or by email.

Good to know

  • Keep the machine awake and connected. The service can keep checking when the agent app is closed.
  • Probes run with your permissions by default. A network-only sandbox is available for API probes.
  • Creating a watch and handling an event can call a model. Scheduled probe checks do not.
  • Agent actions use the host's permission rules. Background work cannot obtain interactive approval.
  • Conditions must be checkable in code. Windows and model-judged conditions are not supported yet.
