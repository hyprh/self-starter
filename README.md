# codex-triggers (working name)

Let Codex act when conditions are met. Tell it in one sentence what to watch, what counts as "it happened", and what to do then. Codex writes a small probe that does the watching; when the condition is met, the task is delivered into a thread and Codex takes it from there. No model calls while waiting.

Current stage: design and feasibility validation.
